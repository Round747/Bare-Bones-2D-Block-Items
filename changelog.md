# v 2.0

**TOTAL: 1062**

### Huge changes for version 2.0!  

195 new blocks! Plant and flower overhaul! Customisation and pack support! 

This version adds all of the remaining blocks, meaing that this packs original goal has been completed! No 3D models are visible anywhere in the inventory. 
Aside from the missing blocks, this version also overhauls the textures many plants and flowers, moving towards this packs new goal of updating item textures without outlines.

This project now has a Github page! You can use it to report bugs and suggest features.

Updates from now on will focus on items and making everything within the inventory visually consistent. I aim to give every item without an outline an outline, to match the style of other blocks. And of course, I will be updating with new Minecraft versions. 26.4 coming soon!

## Notable changes:
- Retextured a multitude of foliage and flower blocks. They now have dedicated inventory sprites, instead of a side profile of the block texture.
- Gave many different items sprites outlines to match the new style, (Items such as arrows, string, feathers, etc.)
- Added all remaining blocks! These include:
    - Wool stairs and slabs blocksets
    - Concrete stairs and slabs blocksets
    - All remaining ore blocks
    - Deepslate tile blockset
    - resin brick blockset
    - Polished deepslate blockset
    - Coral and dead coral blockset
    - Glazed terracotta blockset
    - Copper golem blockset
    - Blocks from the operators tab in the creative inventory, such as the command, structure, and test blocks
- Added compatibility for [Fresh Flowers and Plants.](https://modrinth.com/resourcepack/fresh-flowers-and-plants)
- Lanterns have been revamped once again. You can now tell apart waxed copper lanterns.

### Fixes:
- When outside the inventory, Weskersons Torches now display the vanilla item texture instead of this packs version 
- Added Weskerson's 3D Items support for the redstone repeater and comparator, and the bell.
- Poplar leaves are now supported with Bare Bones - Better Leaves
- Fixed suspicious sand and gravel block models
- When outside the inventory, all lanterns now display the vanilla item texture instead of this packs version.
- This packs banner texture will no longer display in vanilla and recolourful container's GUI's if the banner option is disabled.
- Partial Recolourful containers support for the new blaze powder was added, however it cannot be implemented properly without causing issues for those who use this pack without respackopts. I may revert this since it doesnt look super great.
- All blocks from updates 26.1 onwards have been moved to their respective overlay folders, and their assets will not be loaded on versions below this.
